# Portofolio Lely N.F. Butarbutar

React + Vite + Tailwind CSS.

## Cara install & jalankan

1. Install Node.js (versi LTS) dari https://nodejs.org lalu cek: `node -v` dan `npm -v`
2. Extract zip, buka folder `portfolio` di terminal / VS Code
3. Install dependensi: `npm install`
4. Jalankan mode development: `npm run dev` -> buka http://localhost:5173
5. Build untuk hosting: `npm run build` (hasilnya di folder `dist`)

## Yang perlu kamu ganti
- `src/components/Contact.jsx` -> link GitHub & LinkedIn
- Teks lain ada di `src/components/*.jsx`

## Hosting gratis
Upload folder ke GitHub, lalu hubungkan ke Vercel atau Netlify
(build command: `npm run build`, output directory: `dist`).
